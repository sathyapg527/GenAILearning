# 🚀 GenAILearning

> A comprehensive repository documenting my journey from Machine Learning fundamentals to Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and AI Agents.

## 📌 About

This repository serves as my personal learning journal and hands-on implementation workspace for Generative AI.

It contains notebooks, experiments, assignments, and projects completed while learning through the **Executive Certificate Programme in Generative AI & Agentic AI** offered by **IIT Kharagpur**, along with additional self-learning resources.

The objective is to build production-ready AI applications while documenting concepts, implementations, and best practices.
